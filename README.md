# AFKHeroes

A dark-fantasy AFK / auto-survivors gacha RPG for Windows.

## ⬇️ Download

**[Download the latest version →](https://github.com/mvlgamedev-afk/AFKHeroes/releases/latest)**

On the release page, under **Assets**, download **`AFKHeroes-win-Setup.exe`** and run it.

> Grab the **`-Setup.exe`** file — not the "Source code (zip)". You only need to install once.

## 🚀 Auto-updates

After installing, the game **updates itself automatically** every time you launch it —
you'll always be on the latest version without downloading anything again.

## 💻 Requirements

- Windows 10 / 11 (64-bit)

## 📦 How to install

1. Download `AFKHeroes-win-Setup.exe` from the [latest release](https://github.com/mvlgamedev-afk/AFKHeroes/releases/latest).
2. Run it — the game installs and opens.
3. Play from the Start Menu / desktop shortcut. New versions apply on their own at launch.

## 🧪 Status

Early access / in active development — expect frequent updates.
